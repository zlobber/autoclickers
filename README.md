# Hetic X.1000 - программа для автоматизации рутинных задач
Программа Hetic X.1000 сможет записать и повторить всё, что вы делаете на компьютере вручную.
Всё очень просто, программе достаточно показать на компьютере последовательность действий, она их запишет, а затем воспроизведет с указанной скоростью. С помощью компьютерной программы Hetic X.1000, вы сможете создать свой автокликер, который повторяет действия человека на компьютере, бота для игры или макрос для автоматизации рутинных задач.
